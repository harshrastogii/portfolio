[ NT·04 ]

BushMetrics

Live

BushMetrics is a full-stack spatial app analysing whether the Territory's parks protect a representative cross-section of its land. The reserve network over-represents rugged northern country and under-protects the arid interior — the Tanami, the NT's largest bioregion at ~538,000 km², is a statistically significant cold spot at just 0.6% coverage.

React · Leaflet · FastAPI · Python · GeoPandasopen ↗
[ NT·05 ]

RoadState

Live

An interactive report built from open NT Government traffic data, proving the Territory's real road problem is seasonal access, not congestion. 78% of traffic sits in Darwin alone, while 66% of the year's road closures begin in the wet season — hitting the same remote roads on a predictable, plannable schedule. Every chart carries a plain-English reading so travellers, councils, and emergency services can all use it.

Next.js · React · Visx · TypeScript · Python · pandasopen ↗

Live
