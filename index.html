How I work

01020304

I start with the question, not the dataset.

Open data is easy to download and hard to make mean anything. Before I write a query I want to know what decision is waiting on the answer.

I ship the tool, not the notebook.

Analysis that lives in a notebook dies with the kernel. Every project here ends as something deployed and reachable.

I say what the data doesn't support.

The surrogate validation found the surrogates only modestly useful. Conflux expected two detectors to agree and they didn't.

I build it so it keeps running without me.

Scheduled jobs, no servers to babysit, a plain-English reading on every chart. If you have to ring me to interpret it, I haven't finished.
