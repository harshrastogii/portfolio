Welcome to the library

A short first post — and a template you can copy for everything you write next.

This is a Markdown article. Everything below the dashed header above (the "frontmatter") becomes the page body. Write normally — headings, lists, links, quotes, code — and the build turns it into a styled article that matches the rest of the site.

How headings work

Use ## for main sections and ### for sub-sections. The table of contents on the right builds itself from these automatically.

A sub-section

Reading time and the date in the header are filled in for you. You don't touch the HTML at all.

Writing freely

You can bold, italicise, link to your projects, and drop in lists:

  • One point
  • Another point
  • A third

A blockquote, for the line you want to land.

That's the whole workflow: write the .md, commit, and it appears.
